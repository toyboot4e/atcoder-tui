* atcoder-tui

=atcoder-tui= is an *unofficial* TUI for AtCoder.

** Quick start

#+BEGIN_SRC sh
nix run github:toyboot4e/atcoder-tui
#+END_SRC

** Configuration

Check =~/.config/atcoder-tui/config.jsonc= (Windows: =%APPDATA%\atcoder-tui\=;
comments and trailing commas are allowed):

#+BEGIN_SRC json
{
  "userId": "your_atcoder_id",
  "language": "en"
}
#+END_SRC
