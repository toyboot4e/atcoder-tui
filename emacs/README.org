* atcoder-tui.el

** Requirements

- Emacs 30+
- Have ~atcoder-tui~ on ~exec-path~ or define ~atcoder-tui-program~:
  #+BEGIN_SRC elisp
  (setq atcoder-tui-program '("nix" "run" "github:toyboot4e/atcoder-tui"))
  #+END_SRC
- (Optional) Install the [[https://codeberg.org/akib/emacs-eat][eat]] terminal.

** Try it without installing

#+begin_src sh
nix run github:toyboot4e/atcoder-tui#emacs
#+end_src

** Installation

#+begin_src emacs-lisp
(use-package atcoder-tui
  :vc (:url "https://github.com/toyboot4e/atcoder-tui"
       :lisp-dir "emacs"
       :rev :newest))
#+end_src

** Usage

| Command                        | What it does                                       |
|--------------------------------+----------------------------------------------------|
| ~M-x atcoder-tui~                | open the TUI (re-focuses a running instance)       |
| ~M-x atcoder-tui-session-status~ | show whether a login session is configured         |
| ~M-x atcoder-tui-session-import~ | copy =REVEL_SESSION= from oj / acc                   |
| ~M-x atcoder-tui-session-set~    | paste a cookie value (read hidden, sent via stdin) |
| ~M-x atcoder-tui-session-check~  | verify the session against atcoder.jp              |

** Customization

| Variable                | Default       | What it does                                                           |
|-------------------------+---------------+------------------------------------------------------------------------|
| ~atcoder-tui-program~     | ~nil~           | program name or full command line (list of strings)                    |
| ~atcoder-tui-backend~     | ~auto~          | prefers eat, then vterm, then term; or force one of ~eat~ / ~vterm~ / ~term~ |
| ~atcoder-tui-buffer-name~ | ~*atcoder-tui*~ | name of the buffer running the TUI                                     |

** Notes

- ~atcoder-tui-session-set~ reads the cookie with ~read-passwd~ and pipes it to the CLI's stdin, so the
  value never appears in argv, in the process list, or in the output buffer (the CLI only ever
  prints it masked).
- The package never talks to atcoder.jp itself; everything goes through the app and its rate
  limiter.
